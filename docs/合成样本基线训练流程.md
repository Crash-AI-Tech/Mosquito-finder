# Mosquito Finder 合成样本基线训练流程

本文档用于把当前少量合成样本跑成一条最小可执行训练链路。目标不是得到可上线模型，而是先把数据解析、分组切分、训练、评估、单图预测全部跑通。

## 1. 当前范围

当前流程只针对 [data/synthetic](data/synthetic) 中的合成 ROI 图片。

输入假设：

* 文件名已编码场景、倍率、补光状态、标签和样本编号。
* `mosquito` 为正类。
* `notmosquito` 与 `hardnegative` 统一视为负类。

## 2. 依赖安装

在仓库根目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-ml.txt
```

## 3. 生成 manifest

```bash
.venv/bin/python training/prepare_dataset_manifest.py
```

输出：

* `artifacts/baseline_synthetic/manifest.csv`
* `artifacts/baseline_synthetic/dataset_summary.json`

说明：

* 脚本会把同一个 base 样本及其 `_varA/_varB...` 变体视为同一组。
* 当前采用确定性 3 折分组，不会把同一 base 样本拆进不同 fold。

## 4. 训练基线分类器

```bash
.venv/bin/python training/train_baseline_classifier.py
```

输出：

* `artifacts/baseline_synthetic/stage2_baseline_synthetic.joblib`
* `artifacts/baseline_synthetic/cv_metrics.json`
* `artifacts/baseline_synthetic/cv_predictions.csv`

说明：

* 当前模型是传统机器学习基线，不是深度学习最终方案。
* 特征由灰度缩放图、边缘统计和全局亮度特征组成。
* 训练时会对 `hardnegative` 增加权重，用来提前压误报。

## 5. 单图预测

```bash
.venv/bin/python training/predict_baseline_classifier.py data/synthetic/20260524_AI_whitewall_1x_torchon_mosquito_001.jpg
```

输出为 JSON，包含：

* `mosquito_score`
* `threshold`
* `predicted_label`

## 6. 当前结论边界

这条流程现在的意义是：

* 先把 Stage 2 的训练和评估链路跑通。
* 验证文件命名规范是否足够支撑自动解析。
* 提前暴露 hard negative 和小样本分布问题。

这条流程当前还不能代表：

* 真实设备端可上线精度。
* 真实家庭场景下的泛化能力。
* 可直接转换为 CoreML 的最终生产模型。

## 7. 下一步建议

当真实样本开始补充后，优先做三件事：

1. 把真实 ROI 样本并入同一 manifest 结构。
2. 用真实 hard negative 替换或压低合成负样本占比。
3. 在这条基线跑通后，再决定是否升级到轻量 CNN 或小目标检测器。
